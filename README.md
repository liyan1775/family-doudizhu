# 聚会斗地主

给家里长辈使用的聚会小游戏。家人用微信扫描房间二维码，在手机上进入同一桌，配合大字界面和声音播报完成牌局。

## 项目状态

2026-10-03 更新至 `0.3.1`。手牌优先按可用高度分配空间，并分行错叠，尽量一眼看全；极矮窗口才在手牌区内滚动。补齐三分及末次叫分，地主确定后各自手机播报“您是地主／您是农民”；本人回合手牌与操作区亮起并响短提示音，其他玩家余牌常驻上方。Windows 双击后直接展示电脑主机二维码，手机首页可点选家人开的桌。微信内网页（H5），每人一部手机，先在同一 Wi-Fi 使用。支持二人、三人、四人；二人和四人可选择规则配置。

已通过55项自动化验证与生产构建，覆盖五种玩法整局、重连与消息重试；320×568、320×600、375×667、390×844窗口能首屏看全四人33张牌，320×500能完整看到两行。四种神经配音按座位分配，J／Q／K／A叫勾／皮蛋／凯／ace；女声采用用户认可方向，男声具体声调和力度按用户指示留待后续调试。配有原创小曲，右上角“声音设置”可分别试听和开关。声音后台加载，填称呼和入座照常进行。微信 Android／iPhone 真机扫码、提示音和整套音频听感仍待试玩确认。实际检查记录见 [验证记录](docs/testing.md)。

## 启动与试玩

在 Windows 中双击根目录的 `启动游戏.cmd`，准备完成后会自动打开带大二维码的电脑主机页。第一位家人用微信扫这个码，在手机上填称呼、选人数并创建房间。后来的人可以扫电脑的主页码，在首页点家人开的桌加入；也可以直接扫房主手机上的房间码。所有手机和电脑连接同一个 Wi-Fi，电脑主机页不占玩家座位。

重复双击会继续展示原主机的二维码，保留牌局；常用端口被其他程序占用时会自动换端口，二维码随之调整。若旧版本服务还在运行，请在牌局结束后关闭原启动窗口，再双击，让新版本的房间列表生效。

正在运行游戏的启动窗口请保持打开；后来重复双击的窗口会自动关闭。结束时关闭原启动窗口，当前房间和积分会清空。详细步骤见 [运行说明](docs/run.md)。

当前需求以 [产品需求](docs/product.md) 为准；后续接手请先读 [项目进度](docs/status.md)。

## 文件管理

| 目录             | 用途                               |
| ---------------- | ---------------------------------- |
| `apps/web/`      | 手机网页、界面、语音播放和静态资源 |
| `apps/server/`   | 房间管理、联网同步、服务端校验     |
| `packages/game/` | 不依赖界面的扑克牌与斗地主规则     |
| `tests/`         | 游戏规则、状态流转和联机验证       |
| `scripts/`       | 构建、启动和素材维护工具           |
| `docs/`          | 需求、决策、进度、测试和运行说明   |
| `deploy/`        | 部署配置示例                       |
| `data/`          | 本机运行数据，默认不进入 Git       |

代码、文档和正式素材进入 Git；依赖、构建产物、日志、个人数据和密钥不进入 Git。依赖版本由锁文件固定，更新记录保存在 [CHANGELOG.md](CHANGELOG.md)。
