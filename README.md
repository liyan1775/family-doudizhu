# 聚会斗地主

给家里长辈使用的聚会小游戏。家人用微信扫描房间二维码，在手机上进入同一桌，配合大字界面和声音播报完成牌局。

## 项目状态

2026-10-05 更新至 `0.6.0`。所有家人扫同一个公网二维码；入座后自动尝试RTC直连电脑，失败或断线继续走公网，无需选择网络。两条连接共用玩家身份、座位和消息序号。牌局采用经典横屏布局；微信仍显示竖屏窗口时，网页旋转牌桌，横放手机即可玩。出牌每回合30秒，超时跟牌自动不出，首出自动出最小单张。保留手机开桌、二／三／四人玩法、大字界面和声音播报。

四种神经配音按座位分配，J／Q／K／A叫勾／皮蛋／凯／ace；男声具体声调和力度仍按用户指示留待后续调试。原创配乐与报牌可独立开关，声音加载不拦截入座。公网启动、联机与界面的实际检查和微信真机限制见 [验证记录](docs/testing.md)。

已验证真实局域网和公网玩家同桌完成整局，以及小屏旋转、完整33张手牌、扫码换桌和超时动作。Android／iPhone 微信、运营商流量和异地 Wi-Fi 仍需真机复测；桌面检查不能视为手机验收完成。

## 启动与试玩

双击根目录的 `启动游戏.cmd`，保存或分享唯一的二维码，在家和异地都使用这个码。第一位家人在手机上填称呼、选人数开桌；后来的人扫主页码点桌，或扫房间码加入。电脑主机页不占座位。

已入座手机扫另一桌房间码会自动换桌；旧桌正在打牌时本局结束不计分，其他人重新准备。目标桌已满、已开局或失效时不改动旧桌。更新时先打完、关闭原启动窗口，再双击启动；运行中的旧版不会被强制重启。

第一次自动下载并校验联网组件，此后使用本机缓存；主机电脑需要已经安装 Node.js 22.12或以上（推荐24 LTS），家人的手机不需要安装任何软件。重复双击沿用本次公网入口并保留牌局。旧局域网主机可以继续运行，公网模式使用独立端口和构建，不接管原牌局。

游玩时保持电脑开机联网、原启动窗口打开。关闭窗口会结束本次公网入口并清空房间与积分；重新启动后使用新二维码。同一 Wi-Fi 的离线备用入口为 `启动局域网游戏.cmd`。详细步骤见 [运行说明](docs/run.md) 和 [临时公网方案](docs/public-room.md)。

当前需求以 [产品需求](docs/product.md) 为准；后续接手请先读 [项目进度](docs/status.md)。

## 文件管理

| 目录             | 用途                               |
| ---------------- | ---------------------------------- |
| `apps/web/`      | 手机网页、界面、语音播放和静态资源 |
| `apps/server/`   | 房间管理、联网同步、服务端校验     |
| `packages/game/` | 不依赖界面的扑克牌与斗地主规则     |
| `tests/`         | 游戏规则、状态流转和联机验证       |
| `scripts/`       | 构建、启动和素材维护工具           |
| `docs/`          | 需求、决策、进度、测试和运行说明   |
| `deploy/`        | 部署配置示例                       |
| `data/`          | 本机运行数据，默认不进入 Git       |

代码、文档和正式素材进入 Git；依赖、构建产物、日志、个人数据和密钥不进入 Git。依赖版本由锁文件固定，更新记录保存在 [CHANGELOG.md](CHANGELOG.md)。
