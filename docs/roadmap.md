# 开发路线

## 第一步：家庭试玩版

- 项目目录、Git 和持续维护文档。
- 房间二维码、扫码加入、准备和二／三／四人实时牌局。
- 多种规则配置、文字提示、普通话播报和娱乐积分。
- 手机布局、断线恢复、核心自动化验证。
- 同一 Wi-Fi 试用说明与微信真机测试清单。

## 第二步：按实际试玩调整

- 长辈选牌、字体大小、按钮文案和播报速度。
- 家庭规则、房主换人和旁观需求。
- 0.4.0采用一键临时公网入口，开放跨网络扫码；补齐手机流量及异地微信真机验证。长期域名与部署方案后续确定。
- 发布正式音色，增加可选方言。

## 第三步：长期可靠性

- 持久化房间和积分，处理服务端重启。
- 备份恢复、运行监控、版本发布与回滚。
- 经用户确认后增加机器人、更多玩法或电视展示。
