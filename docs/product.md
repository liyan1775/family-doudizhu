# 产品需求

更新日期：2026-10-05

## 已确认

- 产品是一款长期维护的聚会斗地主游戏。
- 主要用户是家里的长辈。
- 用微信扫描二维码加入游戏。
- 扫码进入微信内网页，先实现家人可玩的版本。
- 游戏有声音播报。
- 每人一部手机，支持二人、三人和四人；第一版在同一 Wi-Fi 使用。
- 主要播报出牌内容，例如“对三”“大王”，参考商业斗地主的短句节奏。
- 长辈来自江苏盐城亭湖，二人和四人规则先调研江苏常见玩法。
- 保持清晰的文件管理；有影响产品方向的问题向用户确认。
- 使用熟悉的斗地主风格配乐，没有指定某款游戏或曲目。
- 出牌声音按座位自动分配不同音色。
- 报牌要有自然语气和短句节奏；用户试听后认可男、女神经配音样本，按此方案继续。
- 可以接受短时间加载，保持原有扫码入座的便捷体验。
- 电脑作为主机，运行 `.cmd` 后直接展示主页二维码，第一位家人无需输入网址即可扫码开桌。
- 后来的家人可以扫描电脑主页码，首页直接显示可加入的房间，点一下加入；也可以扫描房主的房间码。
- 0.4.0升级为一键启动临时公网入口、自动生成二维码，家人使用任意可连通互联网的Wi-Fi或手机流量均可加入，无需安装手机软件、配置网络或输入地址。
- 本轮确认继续沿用手机开桌流程：第一位家人扫码后选人数创建房间，后来的人扫码点桌或扫房间码加入。

- 报牌叫法为J“勾”、Q“皮蛋”、K“凯”、A“ace”；女声小样已认可，男声具体声调与力度按用户指示后续调试，先交付其他功能。
- 本人回合采用明显视觉变化和一声短提示音，替换反复播放“轮到您了”。
- 叫分需完整播报，包含三分和结束叫分的最后一次动作；地主确定时各自手机播报“您是地主／您是农民”，画面明确显示地主称呼。
- 他人余牌数量在选牌时应容易看到，不应要求长辈来回滚动查找。
- 各区域按可用屏幕空间分配，优先保障手牌，尽量一眼看全；部分手机不足两行的手牌面积需要修正。
- 恢复同一局域网玩家的直连体验，同时保留非局域网家人加入同一桌。
- 参照用户提供的经典斗地主布局，微信保持竖屏时也渲染横向牌桌，玩家横放手机操作。
- 出牌每回合30秒：跟牌超时自动不出，首出超时出最小单张。
- 已入座者扫描另一桌邀请码自动换桌；旧桌未结束的本局取消、不计分，其余人回到准备。
- 玩家不应需要理解或执行游戏以外的操作；分享二维码尽量统一，网络优先自动分流，实现明显复杂时再权衡。用户随后明确授权采用单一Quick Tunnel入口、RTCDataChannel自动直连电脑、失败走公网，保持同一身份／座位／消息序号；0.6.0已接入，真机体验待验。

## 首版实现

- 二至四位真人，各用一部手机，同一房间进行游戏。
- 电脑运行服务并自动展示主机扫码页，不占座位；第一位家人扫码进入手机主页创建房间。后续家人扫主页码点选未满的桌，或扫房间码直接入座，房间号保留为备用入口。
- 无需账号，输入称呼即可入座。
- 三人经典斗地主；二人简化／双人抢地主；江浙四人／江苏废炸。来源见 `rules-research.md`，实际细则见 `rules.md`。
- 普通话播报：进入、准备、叫分、牌型、轮到自己、胜负；提供声音开关和试听。
- 大字体、高对比、至少 48px 操作按钮；选牌与出牌分开，减少误触。
- 掉线时保留座位；恢复同一页面后尝试恢复身份和手牌。

地区默认规则和整套音频仍需家人试玩核对。0.3.0使用四套神经配音，每套78句；报牌与配乐独立开关，提供试听、加载进度与失败恢复入口。本人回合采用明显视觉与短提示音，替换回合口播。详见 `audio.md`。

0.5.0采用横向牌桌；宽屏33张一行，较窄横向区域分两行。0.6.0同进程提供统一公网邀请及后台RTC直连，共用房间和身份；掉线暂停剩余时间、叫分不设倒计时属于实施方案。男声声调仍待后续调试。历史手牌比例及声音记录见 [牌局可用性记录](usability.md)，最新检查见 [验证记录](testing.md)。

## 待确认

- 亭湖家庭选择普通四人还是废炸，以及二人抢地主的计数习惯。
- 整套报牌的长辈听感、方言需求和实际操作反馈。
- 后续需要长期稳定服务时的域名、服务器和维护成本；临时公网已作为本轮升级范围。

## 首版验收

1. 双击 `.cmd` 后直接展示电脑二维码；房主扫码到手机开桌，其他手机扫描主页码点选该桌或扫描房间码，均进入相同房间。
2. 每种人数准备后均可完成发牌、叫地主、出牌、结算和下一局。
3. 无法在非本人回合操作，无法出不存在或不符合牌型的牌。
4. 每位玩家只能看到自己的手牌。
5. 长辈能从文字和声音理解当前需要做什么。
6. 手机刷新或短时断网后可以回到原座位。
7. Android 微信和 iPhone 微信各完成至少一局，并实际听到声音。
