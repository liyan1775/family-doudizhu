# 江苏／盐城亭湖规则调研

调研日期：2026-10-03。目标：为家里长辈确定首版默认玩法。

## 结论的范围

公开资料可以确认江浙四人斗地主的共同基础，但未找到可靠的江苏或亭湖玩家覆盖率调查。因此，本项目使用“资料中常见”“多家规则一致”的表述，不宣称某一版本是全省或亭湖最广泛的玩法。

同城游的[江苏四人介绍](https://www.tcy365.com/news/d25006.html)提及盐城，能支持该玩法的地域关联；它不是普及率统计，也没有给出亭湖统一规则。

## 四人：共同基础与地方差异

| 项目 | 调研结论 | 首版处理 |
| --- | --- | --- |
| 牌库、发牌、阵营 | 两副108张，每人25张，8张给地主，一对三 | 两种四人配置共用 |
| 带牌 | 三张和飞机只带对子，不能三带一或四带二 | 两种四人配置共用 |
| 大炸弹 | 4至8张同点数，通常张数越多越大 | 两种四人配置共用 |
| 四王与八炸 | 普通规则四王最大；江苏废炸资料中八炸更大 | 按配置分开 |
| 废炸 | 部分规则限制叫过分的农民可出炸弹次数 | 单独提供江苏废炸配置 |
| A／2下放与蝴蝶 | 江苏废炸资料存在A／2作小牌、飞机带两对连对 | 仅江苏废炸配置启用 |

基础规则交叉参考：[边锋四人规则](https://www.gameabc.com/news/201901/4869.html)（2019）、[JJ四人帮助](https://www.jj.cn/news/320/20110926162600018457.shtml)（2011）、[同城游四人规则](https://www.tcy365.com/news/d26029.html)（2022）。这些是各自产品的规则，较早页面不代表其当前全部模式。

地方版本参考：[同城游江苏废炸](https://www.tcy365.com/news/d28860.html)（2025）。它与同平台的[普通炸弹规则](https://tcy365.com/news/d30464.html)存在四王／八炸排序差异，说明不能混用两篇说明。

## 二人：未发现亭湖独立统一规则

二人公开规则存在明显差异：

- [杀手Online规则](https://www.ss911.cn/Pages/GameRules7.shtml)：54张，每人17张，3张底牌。
- [91y规则](https://m.91y.com/help/guize/98.html)：去掉3和4，46张，每人17张、3张底牌、9张弃牌，带抢地主和让牌。
- [边锋双人说明](https://gameabc.com/news/201905/5308.html)：54张，初始25／26张，另有让牌机制。

这些来源足以证明存在多个产品版本，不能证明其中任一版本在盐城亭湖使用最多。

## 实施建议与实际配置

四人默认选择共同基础较明确的“江浙四人”，同时提供“江苏废炸”，供家人试玩后按习惯选用。二人默认选择“去3和4的双人抢地主”，并保留之前讨论的完整54张简化版。这是产品上的试玩建议，不是普及率结论。

所有房间在创建前显示规则摘要。未被公开资料明确统一的抢地主次数、积分、底牌、废炸边界等，详见 [本项目规则](rules.md)；此文件描述实际实现，不能冒充商业产品完整规则。后续以亭湖家人的实际反馈修订。
