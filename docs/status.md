# 项目进度与交接

## 当前0.6.0（2026-10-05）

用户已授权实现单一Quick Tunnel入口、RTCDataChannel自动直连、失败／断线走公网并保持身份、座位和消息序号。主机页及手机邀请只展示一种公网二维码，不再让玩家选择网络；第一次加载与入座先走公网，直连在后台建立。

- werift 0.24.4作为电脑RTC对端，运行于现有游戏进程；仅数据通道，无媒体采集、STUN／TURN或每人额外进程。
- 同一逻辑连接绑定两路会话；命令稳定ID、递增序号及120秒／256条回执缓存，先去重再校验牌局版本和座位；淘汰后仍拒绝旧序号重放。
- 私人状态同版本发两路，客户端只接收最新版本，回执独立匹配。直连命令350毫秒未回复，经公网重发原信封；1500毫秒心跳、约4.5～5.5秒无响应撤销直连、20秒后台重试为实施参数。
- 单路正常就保持在线与原30秒期限；全部失联才暂停。换桌、退出、替换页面、服务关闭清理RTC及UDP，旧RTC凭据不能操作新座位。
- 84项自动化检查、TypeScript及两种生产构建通过；包含真实Node数据通道、回执丢失后只出一次牌、慢回执、迟到快照、服务器实例更换、两路故障与恢复、五种玩法、手牌隐私和旧桌取消。
- 实际执行正式启动入口并复用同一实例；公网浏览器自动建立IPv4主机候选之间的UDP直连，读到约1毫秒心跳往返。真实Quick Tunnel双人抢地主整局23次出牌／不出，途中分别断开公网与RTC，保持身份、座位和原期限，最终结算。样本与参数见[验证记录](testing.md)，不代表手机性能。
- 测试结束强制关闭本轮启动器，三个Node及cloudflared全部退出，3000监听与游戏UDP端口释放，浏览器测试标签关闭。RTC没有增加每位玩家的进程；当前未留下本轮主机。
- Android／iPhone微信，同Wi-Fi／流量／异地Wi-Fi、mDNS、防火墙、后台返回与旋转触控待真机测试。桌面结果不代替微信验收。

[RTC传输说明](rtc-transport.md)包含实现边界和后续验证。已有0.5.0牌局应先打完并关闭原窗口再启用；独立局域网备用主机仍不共享内存。以下保留历史记录。
