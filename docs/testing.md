# 验证记录

## 2026-10-05：进程排查

用户根据任务管理器截图询问大量Node、node_repl和控制台进程是否是游戏残留。本轮读取实际启动路径、父子关系、创建时间与监听端口，不根据进程显示名结束程序。

- 现场11个Node和6个node_repl均可追溯到Codex及其工具宿主；Node与node_repl的工作集合计约581MB。工具进程存在多批创建时间，但父进程仍在；本轮不能据此判定工具生命周期是否存在问题，也不能将这些进程算作斗地主主机。系统约11.1GB／15.1GB的内存占用是整机数据。
- 本轮检查时没有运行中的斗地主正式／测试主机，3000与3187没有监听。另一组Node和cloudflared属于聚会三国杀，3001在监听；该项目同期有启动变化，本轮没有停止或修改它。正常斗地主公网游玩会保留启动器、游戏服务、联网管理三个Node，以及一个cloudflared；Windows命令／PowerShell和控制台宿主另计，构建工具只在准备阶段使用。
- 额外实际复测：新建隔离启动器，启动真实`apps/server/src/index.ts`及真实`tunnel-worker.mjs`，连接组件用Node夹具模拟，避免创建新的公网邀请；保持一个WebSocket客户端在线后强制结束启动器。游戏服务、联网管理和模拟组件均退出，客户端断开，59016端口释放；临时目录与进程已清理。此实验验证父进程消失后的IPC退出，不等同于所有Windows强杀方式均已验证，也不新增计入75项自动化测试。
- 本轮未发现斗地主启动器重复开桌或关闭后主机残留的证据；既有启动复用、连接失败清理、正式.cmd退出结果见下方。没有批量结束工具进程，也没有更改游戏进程实现。
