# 启动与家庭试玩

## Windows 启动

双击项目根目录 `启动游戏.cmd`，等待自动准备游戏和临时公网入口。检查通过后浏览器展示大二维码；家人用Wi-Fi或手机流量均可扫码，第一位家人在手机上选人数开桌。首次下载联网组件可能较慢，窗口会持续显示进度；下载校验后保存在本机，以后复用。无需注册隧道账户、填写域名或配置路由器。

- 公网游戏已在运行：自动展示同一个公网二维码，房间、手牌和积分继续保留，后来双击的窗口自动关闭。
- 连续双击：后来的启动等待前一次准备完成，最终共用同一个游戏。
- 原局域网游戏仍在运行：继续保留，新公网模式在独立端口和构建运行，两边分别开桌。端口被占用时从3000至3020自动选择，不需要关闭其他程序。
- 公网没有连通：显示中文处理提示，不展示可用公网二维码，也不会自动换成仅局域网可用的码。
- 浏览器没能自动打开：窗口会保留可用的网址，复制到浏览器即可。
- 启动失败：窗口停留并显示中文处理提示，不会闪退。

主机电脑的Node.js未安装时先安装24 LTS；支持22.12或以上。手机无需安装任何软件。第一次准备依赖和联网组件需要访问npm与GitHub；音频仍随项目提供，不依赖在线语音合成。

仅在同一Wi-Fi使用时，可双击 `启动局域网游戏.cmd`；这个备用入口保留原来的局域网启动方式，不需要公网组件。公网和局域网使用不同入口、房间与积分，不会自动迁移正在进行的牌局。

## 家人入座

1. 电脑连接互联网，家人手机连接Wi-Fi或使用移动流量，可以不在同一个地方。
2. 双击电脑的 `启动游戏.cmd`，二维码自动显示。第一位家人用微信扫一扫，在自己的手机上填称呼、选人数并点“创建房间”。
3. 其他家人扫电脑主页码，填称呼后在“家人已经开好的桌”点房主的桌；也可以扫房主手机上的房间码直接加入。远方家人使用电脑页或邀请弹窗的“保存二维码”图片，微信识别二维码即可；也可分享复制的邀请链接。
4. 每人点准备。人齐自动发牌，轮到自己时手牌和操作区亮起，并响一声短提示音；选牌后点出牌。叫分结束会先展示谁是地主，各自手机播报自己的身份。
5. 没听见声音时点“开启声音”试听。

电脑负责运行服务和展示主页二维码，不占玩家座位。保留最初显示“电脑主机已准备好”的启动窗口，保持电脑开机联网，避免休眠。打完关闭窗口，临时公网入口随之结束、旧码失效，房间和积分清空；下一次重新开桌并分享新二维码。关闭浏览器页面本身不会结束游戏。

手机首页每隔约3秒更新可加入的桌，也可以点“重新看看”。已满、已经开始或所有人都离线的桌不显示；多人同时抢最后一个座位时以主机处理结果为准。手动输入6位房间号仍可使用。

若窗口提示原游戏版本较早，会先保留正在进行的牌局。打完后关闭原游戏窗口，再双击启动，新版本才会生效。旧主机尚未重启时，手机可能暂时读不到房间列表，仍可用房主的房间码或房间号加入。

## 选择规则

创建前展开“本桌玩法”即可切换，开局后不能中途换规则。默认二人是46张抢地主，默认四人是江浙四人；另提供54张二人简化和江苏废炸。细则见 [实际规则](rules.md)，地域资料见 [规则调研](rules-research.md)。

## 扫码打不开

公网模式先确认电脑与手机都能上网，使用本次启动的新二维码。入口暂时断开时，电脑页会收起二维码，原启动窗口保持打开；同一联网进程恢复后自动显示。若窗口提示联网组件已退出，关闭本次启动窗口、重新双击并分享新码，重新开桌。

微信对临时域名的访问行为必须以真机为准；微信提示打不开时，可先在手机浏览器尝试同一邀请。临时服务和不同运营商网络可能不可达，不能承诺所有网络始终连通；维护者记录失败环境后再确定稳定部署方案。没有公网可用时，同一Wi-Fi可明确选择局域网备用入口。

以下仅适用于 `启动局域网游戏.cmd`：

- 手机不能使用 `localhost` 或 `127.0.0.1`，需使用电脑局域网地址。
- 电脑扫码页或房间二维码弹窗的“扫码打不开？”可选择电脑的网络地址；电脑没有可用地址时先连接 Wi-Fi，再点“重新检查连接”。
- 访客 Wi-Fi 或路由器 AP 隔离可能阻止设备互相连接。
- Windows 防火墙需允许游戏在家庭网络通信，默认端口3000；自动换端口时以启动窗口和二维码中的端口为准。若防火墙原来只允许3000，还需允许实际使用的端口。不要关闭整个防火墙。
- 先用手机浏览器打开对应地址，区分网络连接与微信页面问题。
- 微信局域网访问及声音表现以真机结果为准，记录到 `testing.md`。

## 声音试玩

入座时自动尝试开启报牌。右上角“声音设置”可试听本桌各座位的声音，也可单独开启《家人围一桌》配乐和调音量。报牌时配乐自动让声；围桌建议只在一部手机开配乐。

0.3.1中，其他玩家余牌始终显示在上方，手牌按可用空间分行排开，尽量不用滑动就能看全；点牌角的点数或花色选中。特别矮的窗口可以在手牌区内轻滑。积分、底牌、邀请和玩法可点右上角“牌桌”查看。短提示音跟随报牌开关，关闭报牌仍保留明显的回合文字与颜色。男声具体声调和力度按用户要求留待后续调试。

声音在后台准备，加载时仍可填称呼、加入和操作。刷新后若没有报牌，请点右上角“恢复声音”；牌局中的恢复入口不再占用手牌高度。配乐等待播放时，进入“配乐与音量”点击播放入口。Android／iPhone微信需各自真机试听。

声音方案、素材来源和维护步骤见 [声音维护](audio.md)。

## 手动命令

在项目目录执行：

```powershell
npm ci
npm run build
npm start
```

这些是维护者使用的固定端口命令。家人日常使用双击入口，它会处理重复运行和端口冲突。命令行停止可按 `Ctrl+C`；Windows 批处理出现 `Terminate batch job (Y/N)?` 时输入 `Y`。家人直接关闭原启动窗口即可。

`.env`可调整`PORT`；临时公网双击模式自动固定回环监听并填写本次HTTPS地址，忽略旧的`HOST`、`PUBLIC_BASE_URL`，无需用户改配置。局域网备用入口与手动命令仍使用`HOST`、`PUBLIC_BASE_URL`，系统环境变量优先；固定外部网址或反向代理遇到端口冲突时不会擅自迁移。配置改变后在牌局结束时关闭原窗口再启动。局域网试玩通常让`PUBLIC_BASE_URL`留空，本机HTTP地址会跟随自动选择的端口更新。

维护者可用 `node scripts/start-local.mjs --public` 运行相同公网流程。构建命令默认仍输出`dist/client`和`dist/server`，公网启动器自动选择独立的`dist/public`，不会覆盖正在提供旧网页的构建。实现、组件来源和真机验收清单见 [临时公网方案](public-room.md)。

## 日常开发

```powershell
npm run dev
npm run typecheck
npm test
npm run build
```

开发网页端口5173，服务端默认3000。手机开发测试时，将 `.env` 的 `PUBLIC_BASE_URL` 填为 `http://电脑局域网IP:5173` 后重启，避免二维码进入旧的生产构建页面。`.env` 参考 `.env.example`，个人配置和密钥不提交 Git。

## 长期保存

Git 保存源码、规则、文档和正式音频，锁文件固定依赖。本地 Git 还需后续配置远程仓库或整目录备份。当前 `data/` 未持久化牌局，复制它不能恢复服务器内存中的房间。
