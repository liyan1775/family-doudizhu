# 启动与家庭试玩

## Windows 启动

双击项目根目录 `启动游戏.cmd`。脚本会在需要时安装锁定依赖，构建当前源码，再启动服务。看到“聚会斗地主已启动”后，用电脑打开 `http://localhost:3000`。

Node.js 未安装时先安装 Node.js 24 LTS。第一次安装依赖需要联网；日常游戏使用随项目提供的音频，不依赖在线语音服务。

## 家人入座

1. 电脑和所有手机连接同一个家用 Wi-Fi。
2. 电脑首页点“手机扫码开桌”。房主用微信扫一扫，在自己的手机上填称呼、选人数并创建房间。
3. 房主手机展示房间二维码，其他家人用微信扫一扫，填称呼后加入。
4. 每人点准备。人齐自动发牌，轮到自己时选牌，再点出牌。
5. 没听见声音时点“开启声音”试听。

电脑负责运行服务。启动窗口保持打开，避免电脑睡眠。关闭或重启服务会清空房间和积分。

## 选择规则

创建前展开“本桌玩法”即可切换，开局后不能中途换规则。默认二人是46张抢地主，默认四人是江浙四人；另提供54张二人简化和江苏废炸。细则见 [实际规则](rules.md)，地域资料见 [规则调研](rules-research.md)。

## 扫码打不开

- 手机不能使用 `localhost` 或 `127.0.0.1`，需使用电脑局域网地址。
- 二维码弹窗的“扫码打不开？”可选择电脑的网络地址。
- 访客 Wi-Fi 或路由器 AP 隔离可能阻止设备互相连接。
- Windows 防火墙需允许游戏 TCP 端口通信，默认3000；按家庭网络情况允许此游戏访问，不要关闭整个防火墙。
- 先用手机浏览器打开对应地址，区分网络连接与微信页面问题。
- 微信局域网访问及声音表现以真机结果为准，记录到 `testing.md`。

## 手动命令

在项目目录执行：

```powershell
npm ci
npm run build
npm start
```

停止：启动终端按 `Ctrl+C`。端口占用时检查旧游戏服务是否仍在运行。

## 日常开发

```powershell
npm run dev
npm run typecheck
npm test
npm run build
```

开发网页端口5173，服务端默认3000。手机开发测试时，将 `.env` 的 `PUBLIC_BASE_URL` 填为 `http://电脑局域网IP:5173` 后重启，避免二维码进入旧的生产构建页面。`.env` 参考 `.env.example`，个人配置和密钥不提交 Git。

## 长期保存

Git 保存源码、规则、文档和正式音频，锁文件固定依赖。本地 Git 还需后续配置远程仓库或整目录备份。当前 `data/` 未持久化牌局，复制它不能恢复服务器内存中的房间。
